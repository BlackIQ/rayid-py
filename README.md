# RayID (Python)

Generate short IDs for logs, events, and traces.

```bash
pip install rayid
```

```python
from rayid import RayID

ray = RayID("digit")

print(ray.gen(16))
```

**Types:** `digit` · `lower` · `upper` · `all`
